# Sistema de Gerenciamento de Serviços Lava-Rápido

## Funcionalidades
Aplicação Desktop com o intuito de gerenciar serviços prestados por um lava-rápido, tendo funcionalidades de adicionar, editar, excluir e buscar serviços no banco de dados.

## Tecnologias Utilizadas
* **Linguagem:** Java 8
* **Banco de Dados:** MySQL
* **Interface Gráfica:** JavaSwing
* **IDE:** NetBeans

## Como Executar e Testar o Projeto

### Pré-Requisitos e Passo a Passo:
* Java Runtime Environment (JRE) 8 ou superior instalado.
* Um banco portado para o MySQL com o Dump do projeto.
* Utilize a IDE Netbeans(preferível a versão 8.2) para ter o funcionamento correto

### Descrição das Funcionalidades:

* Para Adicionar um Servico no Banco de dados, deve-se preencher os campos principais no canto esquerdo da tela e apertar o botão "Cadastrar"

* Para Exluir ou Editar um serviço, deve-se clicar no serviço que quer mudar na tabela na parte de baixo da tela, assim os campos principais serão automaticamente preenchidos pelos dados do serviço, após isso, deve clicar no botão "Excluir" para excluir, ou editar as informações desejadas e clicar no botão "Editar"

* Para pesquisar um serviço na tabela, deve-se preencher o/os dados desejados nos campos menores na parte direita da tela(entre o texto"Pesquisar Serviço" e o botão "Buscar Serviço"), após isso, deve-se clicar no botão "Buscar Serviço", e os resultados da busca serão mostrados na tabela

* Para mostrar a tabela original(com todos os serviços) deve-se clicar no botão "Tabela Completa"

* Para limpar todos os campos, deve-se clicar no botão "Limpar Campos"
